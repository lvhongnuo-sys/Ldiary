问题：
  ✗ 点击"AI 生成"后按钮变灰
  ✗ 没有生成内容
  ✗ 按钮无法恢复
  ✗ 必须刷新页面

原因：
  ❌ 异常处理不完整
  ❌ 使用 return 导致流程提前退出
  ❌ catch 块中没有恢复按钮
  ❌ 没有 finally 块保证

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

修复方案：

1. ✅ API 失败处理
   修改前：return（提前退出）
   修改后：throw new Error()（异常处理）

2. ✅ 解析失败处理
   修改前：仅设置 display（没有按钮恢复）
   修改后：throw new Error()（异常处理）

3. ✅ 异常捕获
   修改前：无按钮恢复，无用户提示
   修改后：alert() 提示错误，finally 恢复按钮

4. ✅ 按钮恢复保证
   修改前：多处分散恢复，容易遗漏
   修改后：finally 块统一保证 100% 恢复

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

代码关键改进：

try{
  // 调用 API
  if(!res.ok){
    throw new Error('API returned status '+res.status);  // ← 改进
  }
  if(!normalized){
    throw new Error('Failed to parse API response');  // ← 改进
  }
  // 成功处理
}catch(e){
  alert('日记生成失败：'+e.message);  // ← 改进：提示用户
  console.log('[LDiary Diary Exception]',e);
}finally{
  btn.disabled=false;  // ✅ 100% 执行
  console.log('[LDiary Generate Complete]');  // ← 改进：完成日志
}
